# DIP-Lab

《数字图像处理》（2026）课程实验与课程设计资料仓库。

## 仓库简介

本仓库用于存放数字图像处理课程的教学资料、实验报告与课程设计（大作业）成果，涵盖从基础实验到综合课程设计的完整材料。

experiments/        各次实验的代码与报告

## 课程信息

课程名称：数字图像处理
开课单位：计算机科学与工程学院
实验与开发平台：MATLAB、OpenCV（C++ / Python / Java）

### 成绩构成

- 实验 20%
- 雨课堂学习与作业 20%
- 课堂考勤 10%
- 终结性课程论文（大作业）50%

终结性考试形式为课程论文（大作业），各项及总评成绩均采用百分制。

## 实验内容

| 实验 | 主题 | 要求 |
| --- | --- | --- |
| 实验一 | 数字图像读取及色彩、亮度、对比度变化 | 完成直方图均衡化和规定化 |
| 实验二 | 数字图像变换与伽马校正 | 选择不同参数完成伽马校正 |
| 实验三 | 数字图像的噪声去除 | 加入高斯噪声与椒盐噪声；用中值滤波、统计排序滤波去噪 |
| 实验四 | 图像的空间域锐化 | 拉普拉斯算子锐化；Canny 算子边缘检测 |
| 实验五 | 频率域低通和高通滤波 | FFT 变换；低通滤波；高通滤波 |
| 实验六 | 数字图像复原 | 施加高斯模糊与运动模糊；维纳滤波复原 |
| 实验七 | 人脸皮肤颜色分层 | 见课程安排 |

实验报告需按模板 [图像处理课程实验报告-2026.doc](course-original-docs/图像处理课程实验报告-2026.doc) 提交。

### 实验检查

- 时间：暂定第 16 周（具体时间另行通知）
- 需准备材料：实验报告（打印版）、程序源码、笔记本电脑
- 流程：由助教或老师检查程序正确性并提问

## 课程设计（大作业）

- 分组：3 人一组，每人有明确分工
- 每人独立完成一份课程论文（设计）报告，按模板 [课程设计报告-图像处理-2026.doc](course-original-docs/课程设计报告-图像处理-2026.doc) 撰写
- 选题：12 周前填好分组与选题表
- 答辩：暂定第 17 周，需准备课程论文（设计）报告、源程序、可执行程序、答辩 PPT

### 选题方向

详见 [任务书及评分标准-数字图像处理2026.docx](course-original-docs/任务书及评分标准-数字图像处理2026.docx)，以下题目任选一题分组完成：

1. 手机文档扫描与可读性增强系统
2. 老照片数字修复与彩色增强系统
3. 低照度彩色监控图像增强与复原系统
4. 人脸美颜相机——肤色保护与细节增强
5. 医学影像综合增强与伪彩色显示系统
6. 工业产品表面缺陷检测预处理系统
7. 自选题目：涵盖本学期所学内容，仅使用传统方法，不使用深度学习方法

### 评分标准

| 项目 | 占比 | 说明 |
| --- | --- | --- |
| 正确性 | 20% | 程序能正常执行，对合法数据均能得到正确结果 |
| 设计合理性 | 20% | 程序架构合理，算法应用正确 |
| 程序功能 | 20% | 完成所有基本功能，按复杂度与完善程度加分 |
| 运行及答辩 | 20% | 思路描述、技术亮点、程序演示、问题回答、PPT 结构 |
| 大作业报告 | 20% | 内容完整，给出设计过程、方法与实验结果并图文分析 |
