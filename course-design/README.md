# 课程设计（大作业）

## 要求

- 3 人一组，每人有明确分工
- 每人独立完成一份课程论文（设计）报告
- 12 周前填好分组与选题表
- 答辩（暂定第 17 周）需准备：报告、源程序、可执行程序、答辩 PPT

## 目录用途

```
course-design/
├── code/      系统源码
├── images/    测试图像与结果图
├── report/    课程设计报告
└── slides/    答辩 PPT
```

## 选题方向

详见 [../../docs/task-and-rubric-2026.docx](../docs/task-and-rubric-2026.docx)，6 个指定题目任选其一，或自选题目（须涵盖本学期所学内容，仅使用传统方法，不使用深度学习）：

1. 手机文档扫描与可读性增强系统
2. 老照片数字修复与彩色增强系统
3. 低照度彩色监控图像增强与复原系统
4. 人脸美颜相机——肤色保护与细节增强
5. 医学影像综合增强与伪彩色显示系统
6. 工业产品表面缺陷检测预处理系统

## 报告结构

按 [课程设计报告模板](../docs/course-design-report-template-2026.doc) 撰写，包含五部分：

1. 设计内容及目标（含组内成员及分工）
2. 方法思想（原理、方案选择、整体流程图）
3. 过程论述（各功能模块实现，仅解释自己完成的部分）
4. 结果分析（定性或定量分析，列出结果图）
5. 课程设计总结（收获、问题与解决、体会）

## 评分标准

| 项目 | 占比 |
| --- | --- |
| 正确性 | 20% |
| 设计合理性 | 20% |
| 程序功能 | 20% |
| 运行及答辩 | 20% |
| 大作业报告 | 20% |

## 可复用模块

`experiments/` 下的七个实验可视为课程设计的基础算法模块，选题时可组合复用：

| 课程设计环节 | 可复用实验 |
| --- | --- |
| 亮度/对比度增强 | 实验一、实验二 |
| 去噪 | 实验三 |
| 锐化与边缘提取 | 实验四 |
| 频域去网纹/纹理抑制 | 实验五 |
| 去模糊复原 | 实验六 |
| 肤色检测与色彩分层 | 实验七 |
