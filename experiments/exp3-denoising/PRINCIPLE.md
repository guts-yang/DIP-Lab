# 实验三：图像去噪 —— 底层原理

> 目标：讲人话，让小白也能在答辩中对答如流。

## 1. 这个实验到底在干什么？

一句话：**给图像"加噪声"再"想办法去掉"，比较哪种去噪方法最管用。**

先人工给干净图加两类噪声（高斯噪声、椒盐噪声），然后用不同的滤波器去噪，最后用 **PSNR** 打分，看谁恢复得最好。

---

## 2. 两类噪声：本质完全不同（超重要）

### 2.1 高斯噪声

每个像素都叠加一个**服从高斯分布（正态分布）的随机扰动**：

$$g(x,y) = f(x,y) + n(x,y), \quad n \sim \mathcal{N}(\mu, \sigma^2)$$

其中概率密度：
$$p(n) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(n-\mu)^2}{2\sigma^2}}$$

- $\mu$ = 均值，通常取 0
- $\sigma$ = 标准差，**决定噪声强度**（$\sigma$ 越大越噪）

特点：**每个像素都"轻微抖动"**，整幅图蒙上一层细腻的颗粒感（像老电视雪花）。

### 2.2 椒盐噪声（脉冲噪声）

随机把**部分像素**直接变成**纯白（255，盐）或纯黑（0，椒）**：

$$g(x,y) = \begin{cases} 0 & \text{以概率 } p_{pepper} \text{（椒，黑点）} \\ 255 & \text{以概率 } p_{salt} \text{（盐，白点）} \\ f(x,y) & \text{以概率 } 1-p_{salt}-p_{pepper} \end{cases}$$

特点：**少数像素被"极端污染"**，其余完好。视觉上是随机的黑白麻点。

**代码实现**：`amount` = 噪声总比例，`salt_vs_pepper` = 盐在其中的占比，用 `np.random.choice` 随机选位置置 0 或 255。

答辩常问：**高斯噪声和椒盐噪声的根本区别？**
> 高斯噪声是**加性**的、每个像素都有、幅度小且连续（服从正态分布）；椒盐噪声是**脉冲**的、只有部分像素、幅度极端（非 0 即 255）。这个区别直接决定了：高斯噪声适合**均值类平滑**滤除，椒盐噪声必须用**中值类（排序统计）**滤除。

## 3. PSNR：怎么评价去噪好坏？（必考）

$$MSE = \frac{1}{MN} \sum_{x,y} \big[f(x,y) - \hat{f}(x,y)\big]^2$$

$$PSNR = 10 \cdot \log_{10}\left( \frac{MAX^2}{MSE} \right) = 10 \cdot \log_{10}\left( \frac{255^2}{MSE} \right)$$

- $f$ = 原始干净图，$\hat{f}$ = 去噪后的图
- $MSE$ = 均方误差，越小越好
- $MAX = 255$（8 位图最大值）
- **PSNR 越大越好**，单位 dB。一般认为 > 30dB 质量较好，> 40dB 非常好

**为什么用对数？** 因为 MSE 的动态范围太大（可能从 0.01 到 10000），取对数压缩到 dB 尺度，方便比较。

答辩常问：**PSNR 有什么局限？**
> PSNR 只统计**像素级的数值误差**，完全不考虑**人眼视觉感受**（结构、纹理、边缘）。有时 PSNR 高的图人眼看着反而更糊（因为过度平滑）。更先进的指标有 SSIM（结构相似性），考虑了亮度、对比度、结构三方面。

答辩常问：**为什么评价去噪需要"原始干净图"？**
> 因为 PSNR 是**有参考（full-reference）** 指标，必须拿去噪结果和真值逐像素比对。实际应用中往往没有真值，只能用无参考指标（如自然场景统计、盲评价）。

## 4. 各类滤波器的原理（核心）

### 4.1 均值滤波 / 算术均值（线性）

$$\hat{f}(x,y) = \frac{1}{mn} \sum_{(s,t) \in S_{xy}} g(s,t)$$

用邻域窗口内所有像素的**平均值**替代中心像素。

- 效果：**平滑**高斯噪声有效（因为高斯噪声零均值，平均会互相抵消）
- 缺点：**把边缘也模糊了**（边缘像素也被平均掉了）
- 对椒盐噪声**效果差**（极端值会污染平均值）

### 4.2 中值滤波（非线性·排序统计）—— 椒盐噪声的克星

$$\hat{f}(x,y) = \underset{(s,t) \in S_{xy}}{\text{median}} \{ g(s,t) \}$$

把窗口内所有像素**排序，取中间那个值**。

**为什么能去椒盐？** 因为椒盐噪声是极端的 0 或 255，排序后排在**两端**，**中位数**几乎不受影响！而中值本身取自窗口中某个真实像素，所以**能保留边缘**。

**为什么对高斯噪声一般？** 高斯噪声每个像素都轻微偏离，中值只是"选一个"，没有平均的"抵消"效应，去噪能力不如均值。

**本实验实测**：椒盐噪声下中值滤波 PSNR 高达 **45.74 dB**，远超其他方法 —— 这就是原因。

答辩常问：**中值滤波为什么能去椒盐噪声又保边？**
> 1. 去椒盐：极值排序后在两端，中位数不受污染；
> 2. 保边：输出值是窗口中**真实存在的某个像素值**，不会造出不存在的中间灰度，跨越边缘时不会被"平均"成过渡值。

### 4.3 最大值 / 最小值滤波（形态学）

- **最大值滤波** $\hat{f} = \max\{g\}$：用窗口内最大值 → 吃掉**暗点（椒）**，用 `cv2.dilate`（膨胀）实现
- **最小值滤波** $\hat{f} = \min\{g\}$：用窗口内最小值 → 吃掉**亮点（盐）**，用 `cv2.erode`（腐蚀）实现

原理：**膨胀取局部最大 → 暗的被周围亮的覆盖；腐蚀取局部最小 → 亮的被周围暗的覆盖。**

答辩常问：**最大值/最小值滤波分别对哪种噪声有效？**
> 最大值（膨胀）去**椒（黑）噪声**；最小值（腐蚀）去**盐（白）噪声**。注意方向：想要"变亮"用膨胀，"变暗"用腐蚀。

### 4.4 中点滤波

$$\hat{f} = \frac{1}{2}\left[ \max\{g\} + \min\{g\} \right]$$

取窗口内最大值与最小值的**算术平均**。对**高斯噪声和均匀噪声**有一定效果（因为随机噪声的最大最小值围绕真值对称），但对椒盐噪声无能为力（最大最小值恰好就是噪声本身）。

### 4.5 修正阿尔法均值滤波（本实验最优的混合噪声方案）

$$\hat{f}(x,y) = \frac{1}{mn - d} \sum_{(s,t) \in S_{xy} - d} g_r(s,t)$$

**做法**：窗口内排序，**去掉最大的 $d/2$ 个和最小的 $d/2$ 个**，剩下的求平均。

**为什么最强？** 它**结合了中值滤波（剔除极端值）和均值滤波（平均抵消随机噪声）的优点**：
- 去掉两端 → 消除椒盐脉冲
- 剩下求平均 → 平滑高斯噪声

所以它对**混合噪声**（既有高斯又有椒盐）效果最好。本实验混合噪声下 **31.41 dB**，为最优。

答辩常问：**修正阿尔法均值滤波为什么适合混合噪声？**
> 因为它"两头都占"：排序截尾去除脉冲（椒盐），对剩余像素平均抑制随机噪声（高斯）。单一的中值或均值只能对付其中一类。

## 5. 线性 vs 非线性滤波（分类，老师爱问）

| | 线性滤波（均值、高斯） | 非线性滤波（中值、最大/最小、阿尔法） |
| --- | --- | --- |
| 运算 | 加权求和（卷积） | 排序、取极值 |
| 对高斯噪声 | 好 | 一般 |
| 对椒盐噪声 | 差 | 极好 |
| 保边缘 | 差（模糊） | 好 |
| 可否用卷积实现 | 可以 | 不可以 |

## 7. 答辩高频问题速答

**Q：为什么均值滤波去高斯噪声有效、中值不行？**
> 高斯噪声零均值且每个像素都独立抖动，**多次平均能让正负偏差互相抵消**（大数定律），所以均值有效。中值只是"挑一个值"，没有平均抵消效应，且会丢失真实细节。

**Q：为什么中值滤波去椒盐噪声有效、均值不行？**
> 椒盐是极端值（0/255），均值会把极端值"分摊"到邻域，污染一片；中值排序后极值在两端，中位数直接忽略它们。

**Q：窗口大小（3x3、5x5）怎么影响？**
> 窗口越大，去噪越强，但**模糊越严重**、细节损失越多。中值滤波 3x3 常保细节更好，5x5 去噪更狠但更糊。需要**权衡**。本实验 `median_k3`(21.97dB) 优于 `median_k5`(20.86dB) 就是这个道理。

**Q：什么是"保边去噪"？**
> 在平滑噪声的同时**保持边缘清晰**。中值滤波、双边滤波、引导滤波都属于这类。双边滤波还额外考虑**灰度相似性**（只平均灰度相近的像素，避免跨边缘平均）。

**Q：椒盐噪声的"盐"和"椒"分别指什么？**
> 盐 = 白点（255，像撒了盐），椒 = 黑点（0，像撒了胡椒粉）。

**Q：如果既有高斯又有椒盐噪声怎么办？**
> 用**修正阿尔法均值滤波**（排序截尾+平均），或先中值去椒盐再均值/高斯去高斯（级联）。本实验验证了阿尔法均值在混合噪声下最优。
