## 实现要点

- 高斯噪声：`numpy.random.normal(mean, sigma)` 叠加后截断。
- 椒盐噪声：随机位置置 255（盐）与 0（椒）。
- 中值滤波：`cv2.medianBlur`，对椒盐噪声最有效，且边缘保持较好。
- 统计排序滤波：
  - 最大值滤波（膨胀）去椒噪声（暗点）
  - 最小值滤波（腐蚀）去盐噪声（亮点）
  - 中点滤波 `(max+min)/2`，对高斯与均匀噪声有效
  - 修正阿尔法均值滤波：去掉 d 个最暗与 d 个最亮后取均值，兼顾高斯与椒盐噪声
